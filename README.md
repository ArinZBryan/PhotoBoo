# PhotoBoo
The haunted-house mirror from hell (Soton Hacktober 2026)

### Install instructions
```
$ git clone https://github.com/ArinZBryan/PhotoBoo.git
$ uv sync
```

### How To Run
To run the main mirror application:
```
uv run photoboo
```

To run the photo voting web-app (note that this will make the app accessible on `localhost:3000`)
```
uv run photoboo-web
```
